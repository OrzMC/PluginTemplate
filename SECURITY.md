# Security Policy

## Reporting a vulnerability

Please do not disclose credentials, exploit details, or an unpatched vulnerability in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow to contact the maintainers privately.

If private reporting is unavailable, open a minimal public issue asking for a private reporting channel. Do not include the vulnerability details or any secrets in that issue.

## Supported versions

Security fixes are provided for the current default branch. Older template snapshots may not receive backported fixes.
